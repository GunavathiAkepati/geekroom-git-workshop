# Contributing

This repo is a workshop, and a pull request to it is part of the workshop. Here are the ground rules.

## What to change

| Step | Add or edit | Branch name |
|---|---|---|
| [Step 11](steps/11-your-first-pull-request.md) | **One new file**: `participants/<your-username>.md` | `add-<your-username>` |
| [Step 12](steps/12-conflict-in-a-real-pr.md) | **One line** in `exercises/cheese-order.md` | `cheese-<your-username>` |

## Rules

1. **Fork, don't branch here.** You don't have write access to this repo, and you don't need it. Fork it, push to your fork, and open the PR from there.
2. **One topic per pull request.** Your Step 11 PR touches only your participants file; your Step 12 PR touches only the cheese-order file.
3. **Don't edit anyone else's file or line.** The one exception is resolving a merge conflict in `exercises/cheese-order.md`, where you keep **everyone's** lines.
4. **Never work on `main`.** Always make a branch.
5. **Use a clear commit message** that says what changed (`Add octocat to participants`, not `update`).
6. **Don't change `steps/`, `reference/` or the other docs** unless you've found a genuine mistake. If you have, say so clearly in the PR description. Typo fixes are welcome.

## ⚠️ It's public

Everything you submit is visible to everyone, permanently. Your username, your commit name and email and the contents of your file are all public. **Don't include** phone numbers, home addresses, passwords, API keys or anything else you wouldn't put on a poster.

## Be kind

Everyone here is learning. Review comments are for helping, not for scoring points.
