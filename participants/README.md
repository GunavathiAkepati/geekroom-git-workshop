# Participants 🍕

Everyone who completes [Step 11](../steps/11-your-first-pull-request.md) adds **one file** here, named after their GitHub username, for example `octocat.md`.

Because every person adds a **different file**, these pull requests never conflict with each other. (The conflicts come in [Step 12](../steps/12-conflict-in-a-real-pr.md).)

**Rules**

- File name = your GitHub username + `.md`
- Only add your own file. Don't edit anyone else's.
- It's public. Keep it friendly and keep it free of private details.

Use this template:

```markdown
# Your name or nickname

- **GitHub username:** your-username
- **Favourite pizza topping:** ...
- **Why I'm learning Git:** one sentence
```
