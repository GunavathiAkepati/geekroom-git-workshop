# Glossary

| Term | Plain English | 🍕 |
|---|---|---|
| **Git** | The tool on your computer that tracks changes to files | The kitchen's system for remembering every pizza |
| **GitHub** | A website that hosts Git repos and adds collaboration | The dining table / restaurant |
| **Version control** | Remembering every version of your work, so mistakes are fixable | A checkpoint in a game |
| **Repository (repo)** | A project folder tracked by Git, including its history | The prep station |
| **Directory** | A folder inside a repo | A tray |
| **File** | One thing Git tracks | A topping |
| **Working directory** | The files you're actively editing right now | The trays on the counter |
| **Initialise (`git init`)** | Turn an ordinary folder into a repo (creates the hidden `.git` folder) | Setting up the prep station |
| **Stage** | Choose which changes go into the next commit | Toppings on the pizza base |
| **Staging area** | The holding space for staged changes | The pizza base |
| **Commit** | A saved snapshot of staged changes, with a message | Baking the pizza |
| **Commit hash (SHA)** | The unique 40-character name of a commit | The pizza's order number |
| **Log / history** | The list of every commit | The kitchen order ticket |
| **Revert** | Add a new commit that reverses an older one | Baking a corrected pizza |
| **Branch** | A separate line of work | A mini pizza for one person |
| **main** | The default, official branch | The communal family pizza |
| **Merge** | Combine one branch into another | Everyone's toppings onto the family pizza |
| **Fast-forward** | A merge where the target hasn't moved, so Git just moves its pointer | Adding toppings after someone left |
| **Three-way merge** | A merge where both branches have new commits | Baking the combined pizza |
| **Merge commit** | The commit that ties two histories together (it has two parents) | The merged pizza |
| **Merge conflict** | Two branches changed the same lines, and Git needs a human to choose | Mom's Mozzarella vs Dad's Cheddar |
| **Conflict markers** | `<<<<<<<`, `=======`, `>>>>>>>` lines Git writes into a conflicted file | |
| **HEAD** | "Where you are right now": your current branch's latest commit | |
| **.gitignore** | A file listing what Git should ignore | Flour bags off the table |
| **Tracked / untracked** | Committed at least once / never committed | |
| **Remote** | A copy of your repo hosted elsewhere, usually GitHub | The dining table |
| **origin** | The default name of the first remote | |
| **upstream** | The name we give the *original* repo when we've forked it | The original restaurant |
| **Push** | Send your commits to the remote | Carrying the pizza to the table |
| **Pull** | Fetch + merge from the remote | Bringing a pizza back to your station |
| **Fetch** | Download from the remote without merging | Looking at what's on the table |
| **origin/main** | Your computer's last known copy of GitHub's `main` | |
| **Ahead / behind** | You have commits the remote lacks / the remote has commits you lack | |
| **Clone** | Copy a repo from GitHub to your computer | |
| **Fork** | Copy someone else's repo to your own GitHub account | Copying a restaurant's recipe |
| **Pull request (PR)** | A request to merge your branch into another, with room for review | Serving your pizza to the restaurant |
| **Maintainer** | The person who reviews and merges pull requests | The head chef |
| **Open source** | Software whose code is public for anyone to read and improve | |
