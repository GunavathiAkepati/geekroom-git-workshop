# Step 0: Start here

**Goal:** Know what Git and GitHub are, why they matter, and have a GitHub account ready.

---

## What exactly is Git?

**Git** is a tool you use **on your computer** to work on coding projects in an organised way.

- It **remembers every version** of your work, so mistakes are fixable.
- That is called **version control**. Think of it as a **checkpoint in a game**: if you mess up, you load the last checkpoint instead of starting again.
- You can create as many files and folders as you like, and Git keeps track of all of them.

## And what is GitHub?

**GitHub** is a **website** where you can store Git projects online, share them with others, and collaborate.

> Basically: **the Google Drive of code and Git projects.**

| | What it is | Where it lives |
|---|---|---|
| **Git** | Tool for tracking your files | On your computer |
| **GitHub** | Website for sharing Git projects | Online |

They are **not the same thing**. You can use Git without GitHub, but GitHub only makes sense because of Git.

## Why learn this?

- **Every project uses Git/GitHub.** Class projects, hackathons, internships, open source: all of it.
- It teaches you to work **independently**: you can experiment freely, break things, and recover.

---

## Make a GitHub account

(Skip this if you already have one.)

1. Go to <https://github.com/signup>.
2. Sign up with an email you can access. Your university email is fine.
3. Pick a username you're happy to see in public. It will appear on your pull request later.
4. Verify your email when GitHub sends the confirmation.

Write your username down. In later steps `<your-username>` means this.
